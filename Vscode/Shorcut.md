# VS Code Keyboard Shortcuts Checklist

A practical checklist to learn and master Visual Studio Code shortcuts, from everyday editing to navigation, debugging, Git, and advanced productivity.

> **Default shortcuts:** Windows/Linux are listed first, followed by macOS where different. Custom keybindings, keyboard layouts, and extensions may change some shortcuts.

## 01. General and Essential

* [ ] `Ctrl + Shift + P` — Open the Command Palette
* [ ] `Ctrl + P` — Quickly open a file
* [ ] `Ctrl + Shift + N` — Open a new VS Code window
* [ ] `Ctrl + N` — Create a new untitled file
* [ ] `Ctrl + O` — Open a file
* [ ] `Ctrl + S` — Save the current file
* [ ] `Ctrl + Shift + S` — Save As
* [ ] `Ctrl + W` — Close the current editor
* [ ] `Ctrl + Shift + T` — Reopen the last closed editor
* [ ] `Ctrl + K`, then `Ctrl + S` — Open Keyboard Shortcuts
* [ ] `Ctrl + ,` — Open Settings

## 02. Editing and Formatting

* [ ] `Ctrl + X` — Cut the current line if nothing is selected
* [ ] `Ctrl + C` — Copy the current line if nothing is selected
* [ ] `Ctrl + V` — Paste
* [ ] `Ctrl + Z` — Undo
* [ ] `Ctrl + Y` — Redo
* [ ] `Ctrl + /` — Toggle line comment
* [ ] `Shift + Alt + A` — Toggle block comment
* [ ] `Shift + Alt + F` — Format the document
* [ ] `Ctrl + ]` — Indent the line
* [ ] `Ctrl + [` — Outdent the line
* [ ] `Home` — Move to the beginning of the line
* [ ] `End` — Move to the end of the line
* [ ] `Ctrl + Home` — Go to the beginning of the file
* [ ] `Ctrl + End` — Go to the end of the file
* [ ] `Alt + Up / Down` — Move the current line up or down
* [ ] `Shift + Alt + Up / Down` — Copy the current line up or down
* [ ] `Ctrl + Shift + K` — Delete the current line

## 03. Selection and Multiple Cursors

* [ ] `Ctrl + D` — Select the next occurrence of the current selection
* [ ] `Ctrl + Shift + L` — Select all occurrences of the current selection
* [ ] `Alt + Click` — Add another cursor
* [ ] `Ctrl + Alt + Up / Down` — Add a cursor above or below
* [ ] `Shift + Alt + Right` — Expand the selection
* [ ] `Shift + Alt + Left` — Shrink the selection
* [ ] `Ctrl + L` — Select the current line
* [ ] `Shift + End` — Select to the end of the line
* [ ] `Shift + Home` — Select to the beginning of the line
* [ ] `Ctrl + Shift + Right` — Select the next word
* [ ] `Ctrl + Shift + Left` — Select the previous word

## 04. Search and Replace

* [ ] `Ctrl + F` — Find text in the current file
* [ ] `Ctrl + H` — Replace text in the current file
* [ ] `Ctrl + Shift + F` — Search across files
* [ ] `Ctrl + Shift + H` — Replace across files
* [ ] `F3` — Find the next match
* [ ] `Shift + F3` — Find the previous match
* [ ] `Alt + Enter` — Select all matches from the Find widget
* [ ] `Ctrl + D` — Add the next matching occurrence to the selection
* [ ] `Ctrl + Shift + J` — Expand search details

## 05. File and Editor Navigation

* [ ] `Ctrl + Shift + Tab` — Switch to the previous editor
* [ ] `Ctrl + Page Up / Page Down` — Switch between editor tabs
* [ ] `Ctrl + 1` — Focus the first editor group
* [ ] `Ctrl + 2` — Focus the second editor group

* [ ] `Ctrl + Shift + E` — Open Explorer
* [ ] `Ctrl + Shift + F` — Open Search

* [ ] `Alt + F12` — Peek Definition

## 06. Code Intelligence and Refactoring

* [ ] `Ctrl + Space` — Trigger suggestions

## 07. Terminal and Command Line

* [ ] `Ctrl + `` — Toggle the integrated terminal
* [ ] `Ctrl + Shift + `` — Create a new terminal

* [ ] `Ctrl + Shift + P` → `Terminal: Kill the Active Terminal` — Close the active terminal session

* [ ] `Shift + F5` — Stop debugging

## 09. Git and Source Control

* [ ] `Ctrl + Shift + G` — Open Source Control
* [ ] `Ctrl + Enter` — Commit staged changes when the Source Control input is focused
* [ ] `Ctrl + Shift + P` → `Git: Clone` — Clone a repository
* [ ] `Ctrl + Shift + P` → `Git: Pull` — Pull changes
* [ ] `Ctrl + Shift + P` → `Git: Push` — Push changes

* [ ] `Ctrl + Shift + P` → `Git: Create Branch` — Create a branch

## macOS Shortcut Guide

On macOS, many `Ctrl` shortcuts above use `Cmd` instead. Some use `Option` instead of `Alt`.

* **Command Palette:** `Cmd + Shift + P`
* **Quick Open:** `Cmd + P`
* **Save:** `Cmd + S`
* **Find:** `Cmd + F`
* **Replace:** `Option + Cmd + F`
* **Search across files:** `Cmd + Shift + F`
* **Terminal:** `Ctrl + ``
* **Toggle comment:** `Cmd + /`
* **Go to Definition:** `F12` (may require function-key settings)
* **Format document:** `Shift + Option + F`

Check the Keyboard Shortcuts editor for your exact platform and keybindings.
