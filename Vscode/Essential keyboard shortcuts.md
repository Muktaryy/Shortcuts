# Useful VS Code Shortcuts for Faster Coding

### 1. Move & Delete Lines
* Move a line up or down:
  * Windows / Linux: Alt + Up / Down Arrow
  * Mac: Option + Up / Down Arrow
  * Tip: Slides the line directly without copying or pasting.
* Delete a full line:
  * Windows / Linux: Ctrl + Shift + K
  * Mac: Cmd + Shift + K

### 2. Multi-Cursor Editing
* Add a cursor above or below:
  * Windows / Linux: Ctrl + Alt + Up / Down Arrow
  * Mac: Cmd + Option + Up / Down Arrow
  * Tip: Type or edit across multiple lines at the same time.
* Select the next matching word:
  * Windows / Linux: Ctrl + D
  * Mac: Cmd + D
  * Tip: Press repeatedly to select more matches (great for renaming tags).

### 3. Emmet Abbreviations (Fast HTML)
Type the shortcut on an empty line, then press Tab or Enter:

* Make a list fast:
  * Type: ul>li*4
  * Result:
    <ul>
      <li></li>
      <li></li>
      <li></li>
      <li></li>
    </ul>

* Add numbered text inside tags:
  * Type: ul>li{Skill $}*3
  * Result:
    <ul>
      <li>Skill 1</li>
      <li>Skill 2</li>
      <li>Skill 3</li>
    </ul>

### 4. Fast Navigation
* Open any file by name:
  * Windows / Linux: Ctrl + P
  * Mac: Cmd + P
* Show or hide the terminal:
  * Windows / Linux / Mac: Ctrl + ` (backtick)
