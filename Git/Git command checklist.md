# Git Command Checklist

A practical checklist to learn and master Git commands, from everyday basics to advanced tools.

## 1. Everyday Basics

* [ ] `git init` — Initialize a repository
* [ ] `git add` — Stage changes
* [ ] `git commit` — Save changes to history
* [ ] `git status` — Check the working tree status
* [ ] `git log` — View commit history
* [ ] `git diff` — Compare changes

## 2. Branching

* [ ] `git branch` — List, create, or delete branches
* [ ] `git switch` — Switch between branches
* [ ] `git merge` — Merge branches
* [ ] `git rebase` — Reapply commits on another base
* [ ] `git cherry-pick` — Apply specific commits
* [ ] `git checkout` — Switch branches or restore files (legacy command)

## 3. GitHub and Remotes

* [ ] `git clone` — Copy a remote repository
* [ ] `git remote` — Manage remote repositories
* [ ] `git fetch` — Download remote updates
* [ ] `git pull` — Fetch and integrate remote changes
* [ ] `git push` — Upload commits to a remote

## 4. Undo and Recovery

* [ ] `git restore` — Restore files or unstage changes
* [ ] `git stash` — Temporarily save working changes
* [ ] `git reset` — Move `HEAD` or unstage changes
* [ ] `git revert` — Undo changes with a new commit
* [ ] `git clean` — Remove untracked files
* [ ] `git reflog` — Inspect recent reference movements

## 5. Inspecting History

* [ ] `git show` — Display commit or object details
* [ ] `git blame` — See who last changed each line
* [ ] `git grep` — Search tracked files for text
* [ ] `git bisect` — Find the commit that introduced a bug
* [ ] `git shortlog` — Summarize commits by author

## 6. Advanced Tools

* [ ] `git tag` — Mark specific points in history
* [ ] `git config` — Configure Git settings
* [ ] `git archive` — Create an archive of repository files
* [ ] `git format-patch` — Export commits as patch files
* [ ] `git apply` — Apply a patch
* [ ] `git worktree` — Work with multiple working trees
* [ ] `git submodule` — Manage nested repositories
* [ ] `git notes` — Attach notes to Git objects
* [ ] `git mv` — Move or rename tracked files
* [ ] `git rm` — Remove tracked files
